turbo-neat

github →

turbo-neat is a hardware-accelerated JAX implementation of NEAT (NeuroEvolution of Augmenting Topologies), the algorithm introduced by Stanley and Miikkulainen in their 2002 paper Evolving Neural Networks through Augmenting Topologies. This project also includes a variety of examples spanning from classic RL tasks to fun multi-agent examples. Evolve agents to race cars or play volleyball through self-play!

NEAT is an evolutionary algorithm that evolves a population of tiny neural networks at the neuron-level against an environment.

One generation of the NEAT algorithm works as follows:

  1. Evaluation: compute the fitness of each member of the population by running environment rollouts. The population is initialized randomly.
  2. Speciation: cluster the population into groups, or 'species' -- this is a tunable mechanism that protects nascent innovation
  3. Reproduction: build the next generation of the population by combining features of high-performing members within each species
  4. Mutation: apply small weight perturbations or add/remove nodes at random to the new population members

This algorithm converges to efficient, performant models across a variety of toy tasks.

When supplied with a vectorizable environment, turbo-neat runs the NEAT algorithm performantly end-to-end in parallel on a GPU.
